# PerRoute 3.5.1

A fix for the Full Installer on computers that did not already have the Windows Packet Filter driver.

## Downloads

| File | Description |
|---|---|
| `PerRoute-Setup-3.5.1.exe` | Full installer. One Administrator approval installs PerRoute, the per-app engine and PerRoute Recovery. |
| `PerRoute-Portable-3.5.1.zip` | Portable build. Extract and run `PerRoute.exe`. |
| `update.json` | Signed update manifest used by *Settings > Updates*. |

**Requirements:** Windows 10 or 11, 64-bit. No Java installation is needed.

## Fixed

- **Per-app routing did not work after a fresh install.** On a computer without the Windows Packet Filter driver, only System proxy worked; Smart per-app mode and per-route routing did nothing. The installer carried the Visual C++ Runtime and the driver but never ran them. It now installs both itself, in order, before the per-app engine, stops with a clear message if either fails, and checks at the end that the driver is registered.
- **Installing the per-app engine from inside PerRoute** now also installs the driver when the engine's setup leaves it out (the file is downloaded from the official release and checked against a pinned SHA-256). The per-app engine counts as ready only when its driver is present, so a half-installed engine is offered for installation again instead of failing silently.

## Good to know

- Windows may ask for a restart after the driver is installed; the installer says so when it does.
- Computers that already had the driver are not affected.
