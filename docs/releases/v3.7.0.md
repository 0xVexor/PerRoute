# PerRoute 3.7.0

Windows and macOS now use the same desktop version. Installer metadata, the app's
version display, package filenames and update comparisons derive from one version
setting. Build numbers remain deterministic for the source commit.

## Changes

- Replace personal branding with PerRoute in the Windows installer, uninstaller,
  recovery tool, installed publisher and browser extension metadata.
- Update repository, download and update-feed links to `0xVexor/PerRoute`.
- Add CI builds for the Windows x64 offline installer, portable app and browser
  bundle, and the Apple Silicon macOS helper-enabled preview package.
- Add Safari IPv4 TCP routing, verified grouping of app helpers and reviewed
  migration of older executable selections.
- Expand portable Windows/macOS regression coverage and real-core macOS advanced
  routing lifecycle tests.

## Downloads

Windows x64: choose `PerRoute-Setup-3.7.0.exe` for installation or
`PerRoute-Portable-3.7.0.zip` for a portable application. The offline installer also
includes the optional browser runtime and extension.

Apple Silicon macOS 13+: choose the `PerRoute-3.7.0-…-macos-arm64-preview.pkg`.
The companion `PerRoute-macOS-arm64-3.7.0.zip` contains the same package,
installation/recovery instructions, notices, diagnostics collector and complete
modified routing-engine source. Intel macOS packages are not included.

Check `SHA256SUMS` after downloading. The BUILD JSON files identify each platform's
exact source revision, common version and deterministic build number.

## macOS preview status

The app and helper use a persistent local signing identity. The PKG is unsigned and
unnotarized, so this is a controlled preview rather than general macOS distribution.
The same identity is retained for compatible helper upgrades.

Installed build 67 established Chrome main routing, main-server restart fallback,
Auto initial selection, a temporary dedicated override and return, per-app counter
observations and normal Disconnect cleanup. Those observations came from the prior
3.6.0 candidate; CI packaging does not establish fresh installed acceptance of 3.7.0.
Aggregate limits, controlled native failover/rollback, strict unselected-app controls
and full inspector accounting still have installed acceptance gaps. UDP/QUIC, IPv6,
guaranteed DNS leak protection and a per-app kill switch remain outside macOS scope.

## Updating

Disconnect and quit PerRoute before installing an update. Preserve the existing
settings and helper signing identity. Read the macOS package's maintenance guidance
before uninstalling or migrating an installation with a different helper identity.

This release provides manual downloads. An authenticated `update.json` requires the
separate existing release-signing key; unsigned update manifests are never accepted.

The previous release remains the latest automatic-update source until a signed
3.7.0 update manifest is available. This release's manual downloads remain public.
