# PerRoute 3.7.1

A fix release for Windows per-app routing and the application list.

## Changes

- Smart per-app routing no longer leaves web traffic direct when a filtering DNS resolver answers with
  a fake private address. Traffic is routed by the site name read from the connection.
- Installed applications: Chrome, Office apps, Node.js, Git GUI and other classic programs that were
  missing from the list are now found.
- Packaged (Store) applications show their icons.
- Problems that were silently ignored while reading the application list are recorded and shown by the
  connection doctor.
- Internal clean-up of the controller (application catalog, doctor, subscription tracking) and removal of
  an unused interface. No change in behaviour.

## Downloads

Windows x64: choose `PerRoute-Setup-3.7.1.exe` for installation or `PerRoute-Portable-3.7.1.zip` for a
portable application. Check `SHA256SUMS` after downloading.
